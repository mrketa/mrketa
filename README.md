## How I build

| Principle | What it means |
|---|---|
| **Solve the actual friction** | A utility should remove work, not introduce another workflow. |
| **Keep authority narrow** | Local-first, bounded, explicit, and inspectable by default. |
| **Ship the complete path** | Setup, verification, recovery, rollback, and documentation are part of the product. |
| **Prefer boring reliability** | Clear contracts and deterministic behavior beat unnecessary abstraction. |
